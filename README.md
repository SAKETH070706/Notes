# Notes App 📝

A simple and intuitive **note-taking web application** built with **React** and **Vite**. It allows users to create, edit, delete, and restore notes with a clean interface.

---

## 🚀 Features
- Create new notes with a single click
- Edit and save notes in real time
- Search notes by title or content
- Delete notes to Trash and restore them later
- Permanently delete notes from Trash
- Responsive layout with sidebar navigation

---

## 🛠️ Tech Stack
- **Frontend:** React (Hooks, Components, State Management)
- **Build Tool:** Vite
- **Styling:** CSS
- **Storage:** LocalStorage (for persisting notes)
